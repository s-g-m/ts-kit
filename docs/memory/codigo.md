# Memoria de Código

Registro canónico del contexto histórico, justificaciones y alternativas descartadas en código para este proyecto.

|      ID      |   Fecha    | Decisión tomada                                                                                                                                                                                                                                                                                                 | ¿Por qué? (Justificación)                                                                                                                                                                                                                                                     | Alternativas descartadas y motivo                                                                                                                                            |
| :----------: | :--------: | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MEM-CODE-001 | 2026-11-21 | Las integraciones con proveedores viven en Kit como módulos opcionales con ruta propia (`firebase/web`, `firebase/native`, `expo/network`, `expo/sqlite`) y sus SDK son `peerDependencies` opcionales; los consumidores no importan esos SDK.                                                                   | Mismo criterio que go-kit (auth, storage): cambiar de proveedor no toca la aplicación, y la ruta propia evita que la web arrastre React Native.                                                                                                                               | Dejar los adaptadores en cada aplicación: duplica código y acopla las apps al SDK. Un único módulo con todo: obliga a instalar todos los SDK.                                |
| MEM-CODE-002 | 2026-11-21 | `errs.resolveMessage(error, { byCode, byType, fallback })` resuelve el texto para el usuario; los textos los define la aplicación.                                                                                                                                                                              | El mecanismo es genérico; el idioma y la redacción son del producto.                                                                                                                                                                                                          | Textos en Kit: mezcla conceptos de negocio.                                                                                                                                  |
| MEM-CODE-003 | 2026-11-21 | `httpcli` clasifica los fallos de red como `SERVICE_UNAVAILABLE` (antes `INTERNAL`) y expone `bearerInterceptor(getToken)`, que también usa `AuthManager.attachToHttpClient`.                                                                                                                                   | Un fallo de red es un servicio inalcanzable, igual que un 5xx, y las apps no deben comparar códigos para detectarlo; el interceptor estaba duplicado en los consumidores.                                                                                                     | Mantener `INTERNAL`: obliga a cada app a tratar `HTTP_CLIENT_NETWORK_ERROR` a mano.                                                                                          |
| MEM-CODE-004 | 2026-11-21 | Con el consumo por `file:` (enlace simbólico), los consumidores resuelven los paquetes compartidos desde la aplicación: `resolve.dedupe` en Vite y `resolver.resolveRequest` en Metro.                                                                                                                          | Kit instala los SDK como dependencias de desarrollo; sin redirección, los bundlers cargarían dos copias de React, Firebase o React Native.                                                                                                                                    | `install-links=true`: copia Kit en cada instalación y pierde los cambios locales en vivo.                                                                                    |
| MEM-CODE-005 | 2026-11-21 | ts-kit usa Biome con la misma configuración que los frontends (`npm run format`, `npm run lint`); la regla `useHookAtTopLevel` se desactiva en `base/` y `auth/`.                                                                                                                                               | Kit y consumidores deben verse igual. Biome toma por hooks de React métodos como `HttpClient.useRequestInterceptor`, que no lo son.                                                                                                                                           | Renombrar esos métodos: rompe la API pública por un falso positivo.                                                                                                          |
| MEM-CODE-006 | 2026-11-22 | `httpcli` lee el sobre de error de go-kit (`{ error: { code, message, details } }`): el código del servidor es el código del `AppError` y `details` guarda solo los detalles internos; `errs` suma los tipos `GONE`, `PRECONDITION_FAILED`, `PRECONDITION_REQUIRED` y `TOO_MANY_REQUESTS` (410, 412, 428, 429). | Los consumidores no podían distinguir `INVITATION_INVALID` de `POLICY_ACCEPTANCE_REQUIRED`: todo llegaba como `HTTP_CLIENT_HTTP_ERROR` y 410 o 428 como `INTERNAL`, sin texto por código (fase 2 de Sport). Es el mismo catálogo de tipos que go-kit (MEM-CODE-001 de Sport). | Leer `details.error.code` en cada app: duplica el parseo en todos los consumidores. Mantener 410/428 como `INTERNAL`: un enlace vencido se mostraría como falla del sistema. |
